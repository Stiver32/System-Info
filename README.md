# Py-SystemInfo

A Python utility for collecting and displaying basic system information for troubleshooting and documentation.

## Purpose

This project was built to practice Python scripting while creating a simple tool that could support endpoint troubleshooting.

## Features

- Collects operating system information
- Displays hardware or system details
- Provides formatted output for quick review
- Can be expanded for support documentation or diagnostics

## Technologies Used

- Python
- System information libraries/modules
- Command-line interface

## Learned...

- Python scripting
- Reading system/environment data
- Formatting command-line output
- Building small diagnostic tools
